Part (a): Formal Topological Definitions for Signal Flow Graphs

A Signal Flow Graph (SFG) is a directed graph consisting of a network of nodes connected by directed line segments called branches. Each node represents a system variable, and each branch acts as a unidirectional signal transmitter governed by an algebraic relation.

Topological Term Formal Definition (Prof. MM Lecture Notes) Mathematical / Physical Meaning
1. Node ($x_k$) A point representing an independent or dependent system variable. Signals entering a node sum together algebraically. Algebraic junction: $x_k = \sum_{j} t_{jk} x_j$.
2. Source Node (Input Node) A node having only outgoing branches and no incoming branches. Independent excitation / reference command $R(s)$. $\deg^-(x_0) = 0, \deg^+(x_0) \ge 1$.
3. Sink Node (Output Node) A node having only incoming branches and no outgoing branches. Controlled output response $C(s)$. $\deg^+(x_n) = 0, \deg^-(x_n) \ge 1$.
4. Path A continuous, connected sequence of directed branches traversed strictly in the direction of the branch arrows, passing through no node more than once. Unidirectional chain of signal transmission without repetition.
5. Forward Path A path that starts at a source node and ends at a sink node, traversing no intermediate node more than once. Direct signal transmission route from input $R(s)$ to output $C(s)$.
6. Forward Path Gain ($P_k$) The product of the branch gains (transmittances) encountered along the $k$-th forward path: $$P_k = \prod_{b \in P_k} t_b$$ Net forward amplification factor along the $k$-th direct path.
7. Feedback Loop (Loop) A closed path that starts and ends at the exact same node, passing through no other node more than once. Closed feedback loop causing circular signal flow.
8. Loop Gain ($L_i$) The product of all branch gains (transmittances) around the $i$-th closed feedback loop: $$L_i = \prod_{b \in L_i} t_b$$ Open-loop transmission factor around a closed feedback path.
9. Non-Touching Loops Two or more feedback loops that do not share any common node (their node vertex sets are strictly disjoint: $V(L_i) \cap V(L_j) = \emptyset$). Topologically independent loops with zero mutual interaction.
Part (b): Statement & Explanation of Mason's Gain Formula

Statement: The overall transmission (closed-loop transfer function) between an input source node $R(s)$ and an output sink node $C(s)$ of an LTI system represented by a signal flow graph is given by:

$$\mathbf{T = \frac{C(s)}{R(s)} = \frac{\sum_{k=1}^N P_k \Delta_k}{\Delta}}$$

Explanation of Symbols:

  • $N$: Total number of distinct forward paths from input source $R(s)$ to output sink $C(s)$.
  • $P_k$: Path gain (transmittance product) of the $k$-th forward path.
  • $\Delta$: Graph determinant (characteristic determinant) of the entire signal flow graph, defined by the alternating series: $$\mathbf{\Delta = 1 - \sum L_i + \sum L_i L_j - \sum L_i L_j L_k + \dots}$$ where:
    • $\sum L_i$ = Sum of loop gains of all individual feedback loops in the graph.
    • $\sum L_i L_j$ = Sum of products of loop gains of all possible combinations of two non-touching loops.
    • $\sum L_i L_j L_k$ = Sum of products of loop gains of all possible combinations of three non-touching loops.
  • $\Delta_k$: Cofactor of the $k$-th forward path. It is evaluated as the value of $\Delta$ for that portion of the signal flow graph that does not touch (shares no node with) the $k$-th forward path: $$\Delta_k = 1 - \sum L_{i,k} + \sum L_{i,k} L_{j,k} - \dots$$ where all loops touching the $k$-th forward path are set to zero. If all feedback loops share at least one node with path $P_k$, then $\Delta_k = 1$.
Exam Strategy Note (Prof. MM Standard): In Jadavpur University semester examinations, never derive Mason's Gain formula using matrix determinants or Cramer's rule unless explicitly asked (which has never occurred in the last 15 years). Always state the formula clearly, define every symbol ($N, P_k, \Delta, \Delta_k, L_i$), and specify how non-touching loop products are accounted for.

Method 1 Block Diagram Reduction Technique [JU 2023 Regular Q3b OR, 8 Marks]

We reduce the system systematically by resolving inner feedback loops and parallel feedforward branches:

Step 1: Isolate the Output Feedforward Path ($G_4$):
Observe Summer 3 at the output: the controlled variable $C(s)$ is the sum of the transmission through block $G_3$ (let us denote this signal as $Y(s)$) and the feedforward signal through $G_4$: $$C(s) = Y(s) + G_4 R(s)$$ Therefore, we first evaluate the closed-loop ratio $\frac{Y(s)}{R(s)}$ for the main feedforward cascade, and subsequently superimpose $G_4$.

Step 2: Eliminate the Inner Feedback Loop ($G_2$ with Feedback $H_1$):
At Summer 2, the feedback signal from $H_1$ enters with a minus ($-$) sign. The internal forward block is $G_2$. Eliminating this local negative feedback loop yields the equivalent block $G_{2,\text{inner}}$: $$\mathbf{G_{2,\text{inner}}(s) = \frac{G_2}{1 + G_2 H_1}}$$

Step 3: Cascade with $G_3$ and Eliminate Feedback Loop $H_2$:
The forward path between Summer 2 and signal $Y(s)$ becomes the series cascade of $G_{2,\text{inner}}$ and $G_3$: $$G_{23}(s) = G_{2,\text{inner}} \cdot G_3 = \frac{G_2 G_3}{1 + G_2 H_1}$$ Feedback loop $H_2$ wraps around this block back to Summer 2 with a negative ($-$) sign. Eliminating loop $H_2$ yields: $$G_A(s) = \frac{G_{23}}{1 + G_{23} H_2} = \frac{\frac{G_2 G_3}{1 + G_2 H_1}}{1 + \frac{G_2 G_3 H_2}{1 + G_2 H_1}} = \mathbf{\frac{G_2 G_3}{1 + G_2 H_1 + G_2 G_3 H_2}}$$

Step 4: Cascade with $G_1$ and Eliminate Positive Feedback to Summer 1:
Connecting $G_1$ in cascade with $G_A(s)$, the forward gain from the output of Summer 1 to $Y(s)$ is: $$G_{\text{fwd1}}(s) = G_1 \cdot G_A(s) = \frac{G_1 G_2 G_3}{1 + G_2 H_1 + G_2 G_3 H_2}$$ Now inspect the feedback line from block $H_1$ to Summer 1. The pick-off point is located at signal $X_2$ (between $G_2$ and $G_3$). Since $Y(s) = G_3 X_2(s)$, we have $X_2(s) = \frac{Y(s)}{G_3}$.
Hence, the feedback signal reaching Summer 1 through $H_1$ is: $$B_1(s) = H_1 X_2(s) = \frac{H_1}{G_3} Y(s)$$ Crucially, this signal enters Summer 1 with a positive ($+$) sign (positive feedback!).
Using the closed-loop formula for positive feedback ($1 - GH$): $$\frac{Y(s)}{R(s)} = \frac{G_{\text{fwd1}}}{1 - G_{\text{fwd1}} \cdot \left(\frac{H_1}{G_3}\right)} = \frac{\frac{G_1 G_2 G_3}{1 + G_2 H_1 + G_2 G_3 H_2}}{1 - \frac{G_1 G_2 G_3 \cdot \frac{H_1}{G_3}}{1 + G_2 H_1 + G_2 G_3 H_2}}$$ Simplifying the denominator: $$\mathbf{\frac{Y(s)}{R(s)} = \frac{G_1 G_2 G_3}{1 + G_2 H_1 + G_2 G_3 H_2 - G_1 G_2 H_1}}$$

Step 5: Combine with Parallel Feedforward Branch $G_4$:
Substitute $Y(s)$ back into $C(s) = Y(s) + G_4 R(s)$: $$\frac{C(s)}{R(s)} = \frac{Y(s)}{R(s)} + G_4 = \frac{G_1 G_2 G_3}{1 + G_2 H_1 + G_2 G_3 H_2 - G_1 G_2 H_1} + G_4$$ Expressing over a common denominator: $$\mathbf{\frac{C(s)}{R(s)} = \frac{G_1 G_2 G_3 + G_4 (1 + G_2 H_1 + G_2 G_3 H_2 - G_1 G_2 H_1)}{1 + G_2 H_1 + G_2 G_3 H_2 - G_1 G_2 H_1}} \quad \blacksquare$$

Method 2 Signal Flow Graph & Mason's Gain Formula [JU 2023 Regular Q3b, 8 Marks]

We convert the block diagram into an SFG by identifying discrete nodes at input $R(s)$, outputs of Summer 1 ($x_2$), Summer 2 ($x_3$), block $G_2$ ($x_4$), block $G_3$ ($x_5$), Summer 3 ($x_6$), and output $C(s)$ ($x_7$).

1. Forward Paths ($P_k$):

  • Path 1: $R \to x_2 \to x_3 \to x_4 \to x_5 \to x_6 \to C \implies \mathbf{P_1 = (1)(G_1)(G_2)(G_3)(1)(1) = G_1 G_2 G_3}$
  • Path 2: $R \xrightarrow{G_4} x_6 \to C \implies \mathbf{P_2 = (G_4)(1) = G_4}$

2. Individual Closed Loops ($L_i$):

  • Loop 1 ($L_1$): $x_3 \to x_4 \to x_3$ with path transmittance $G_2$ and feedback $-H_1$: $$\mathbf{L_1 = -G_2 H_1}$$
  • Loop 2 ($L_2$): $x_3 \to x_4 \to x_5 \to x_3$ with path $G_2 G_3$ and feedback $-H_2$: $$\mathbf{L_2 = -G_2 G_3 H_2}$$
  • Loop 3 ($L_3$): $x_2 \to x_3 \to x_4 \to x_2$ with forward path $G_1 G_2$ and positive feedback $+H_1$: $$\mathbf{L_3 = +G_1 G_2 H_1}$$

3. Non-Touching Loop Analysis:

Every single loop ($L_1, L_2, L_3$) contains node $x_4$ (the pick-off point between $G_2$ and $G_3$). Since all loops share node $x_4$, there are no non-touching loop pairs: $$\sum L_i L_j = 0$$

4. System Graph Determinant ($\Delta$):

$$\Delta = 1 - (L_1 + L_2 + L_3) = 1 - (-G_2 H_1 - G_2 G_3 H_2 + G_1 G_2 H_1)$$ $$\mathbf{\Delta = 1 + G_2 H_1 + G_2 G_3 H_2 - G_1 G_2 H_1}$$

5. Path Cofactors ($\Delta_k$):

  • Cofactor $\Delta_1$ (for $P_1$): Path 1 traverses nodes $\{R, x_2, x_3, x_4, x_5, x_6, C\}$, touching all three feedback loops. Setting touching loop gains to zero: $$\mathbf{\Delta_1 = 1}$$
  • Cofactor $\Delta_2$ (for $P_2$): Path 2 traverses only nodes $\{R, x_6, C\}$. Nodes $\{x_2, x_3, x_4, x_5\}$, which comprise all three loops $L_1, L_2, L_3$, are completely untouched by $P_2$! Hence, all three loops remain active in the cofactor: $$\mathbf{\Delta_2 = 1 - (L_1 + L_2 + L_3) = \Delta = 1 + G_2 H_1 + G_2 G_3 H_2 - G_1 G_2 H_1}$$

6. Overall Closed-Loop Transfer Function:

$$\frac{C(s)}{R(s)} = \frac{P_1 \Delta_1 + P_2 \Delta_2}{\Delta} = \frac{(G_1 G_2 G_3)(1) + G_4 \Delta}{\Delta} = \frac{G_1 G_2 G_3}{\Delta} + G_4$$ $$\mathbf{\frac{C(s)}{R(s)} = \frac{G_1 G_2 G_3 + G_4 (1 + G_2 H_1 + G_2 G_3 H_2 - G_1 G_2 H_1)}{1 + G_2 H_1 + G_2 G_3 H_2 - G_1 G_2 H_1}} \quad \blacksquare$$
Pedagogical Check • Method Concordance: Notice that Block Diagram Reduction and Mason's Gain Formula produce the exact same mathematical expression down to every individual sign. This confirms both solutions.

Multi-Loop Feedback System with Parallel Forward Blocks (Fig. P-10)

“Q10b. Use the block diagram reduction technique and obtain the overall transfer function of the system given in Fig. P-10. [05 M]
Q10c. Draw the signal flow graph for the system depicted in Fig. P-10. Use Mason's Gain Formula and find out the overall transfer function of the system. [07 M]”
Fig. 4.2: Authentic Scan of Fig. P-10 from Jadavpur University B.E.E. 3rd Year 1st Sem Examination Paper (2019)
Method 1 Block Diagram Reduction Technique [JU 2019 Q10b, 5 Marks]

We reduce the interconnected diagram step-by-step using elementary equivalence rules:

Step 1: Move the Pick-off Point of $H_2$ Ahead of Block $G_2$:
In Fig. P-10, the feedback line $H_2$ is tapped after $G_2$. Moving this takeoff point to the left of block $G_2$ (directly to the output of $G_1$) introduces an additional block $G_2$ into the feedback branch.
Therefore, the feedback transmittance from the output of $G_1$ back to Summer 2 becomes: $$H_2'(s) = G_2 H_2$$

Step 2: Combine the Parallel Feedforward Blocks ($G_2$ and $G_4$):
Now that the pick-off point has been moved, blocks $G_2$ and $G_4$ both originate from the same node (output of $G_1$) and both terminate at Summer 3 with positive signs.
Combining these two parallel branches: $$\mathbf{G_{\text{parallel}}(s) = G_2 + G_4}$$

Step 3: Eliminate the Independent Inner Feedback Loops:
The diagram now decouples into two standard closed loops:

  • Loop 1 (at Summer 2): Forward block $G_1$ with negative feedback $H_2' = G_2 H_2$: $$G_A(s) = \frac{G_1}{1 + G_1 H_2'} = \mathbf{\frac{G_1}{1 + G_1 G_2 H_2}}$$
  • Loop 2 (at Summer 3): Forward block $G_3$ with negative feedback $H_3$: $$G_B(s) = \mathbf{\frac{G_3}{1 + G_3 H_3}}$$

Step 4: Cascade the Three Forward Subsystems:
The forward path between Summer 1 and output $C(s)$ is the series cascade of $G_A(s)$, $G_{\text{parallel}}(s)$, and $G_B(s)$: $$G_{\text{cascade}}(s) = G_A(s) \cdot G_{\text{parallel}}(s) \cdot G_B(s) = \frac{G_1 (G_2 + G_4) G_3}{(1 + G_1 G_2 H_2)(1 + G_3 H_3)}$$

Step 5: Eliminate the Outer Feedback Loop $H_1$:
The entire forward cascade is enclosed by an overall negative feedback loop through $H_1$ returning to Summer 1. Applying the feedback formula: $$\frac{C(s)}{R(s)} = \frac{G_{\text{cascade}}}{1 + G_{\text{cascade}} H_1} = \frac{\frac{G_1 (G_2 + G_4) G_3}{(1 + G_1 G_2 H_2)(1 + G_3 H_3)}}{1 + \frac{G_1 (G_2 + G_4) G_3 H_1}{(1 + G_1 G_2 H_2)(1 + G_3 H_3)}}$$ Clearing the compound denominator: $$\mathbf{\frac{C(s)}{R(s)} = \frac{G_1 (G_2 + G_4) G_3}{(1 + G_1 G_2 H_2)(1 + G_3 H_3) + G_1 (G_2 + G_4) G_3 H_1}} \quad \blacksquare$$

Method 2 Signal Flow Graph & Mason's Gain Formula [JU 2019 Q10c, 7 Marks]

We map the system directly into a Signal Flow Graph:

1. Forward Paths ($P_k$):

  • Path 1 (via $G_2$): $R \to x_2 \to x_3 \to x_4 \to x_5 \to x_6 \to x_7 \to C \implies \mathbf{P_1 = G_1 G_2 G_3}$
  • Path 2 (via $G_4$): $R \to x_2 \to x_3 \to x_4 \xrightarrow{G_4} x_6 \to x_7 \to C \implies \mathbf{P_2 = G_1 G_4 G_3}$

2. Individual Feedback Loops ($L_i$):

  • Loop 1 ($L_1$): $x_3 \to x_4 \to x_5 \to x_3$ with gain $\mathbf{L_1 = -G_1 G_2 H_2}$
  • Loop 2 ($L_2$): $x_6 \to x_7 \to x_6$ with gain $\mathbf{L_2 = -G_3 H_3}$
  • Loop 3 ($L_3$): Outer loop via $G_2$: $x_2 \to x_3 \to x_4 \to x_5 \to x_6 \to x_7 \to x_2$ with gain $\mathbf{L_3 = -G_1 G_2 G_3 H_1}$
  • Loop 4 ($L_4$): Outer loop via $G_4$: $x_2 \to x_3 \to x_4 \xrightarrow{G_4} x_6 \to x_7 \to x_2$ with gain $\mathbf{L_4 = -G_1 G_4 G_3 H_1}$

3. Non-Touching Loop Analysis:

Inspect the nodes occupied by each loop:

  • $V(L_1) = \{x_3, x_4, x_5\}$
  • $V(L_2) = \{x_6, x_7\}$
Since $V(L_1) \cap V(L_2) = \emptyset$, loops $L_1$ and $L_2$ are strictly non-touching!
Product of non-touching pair: $$\mathbf{L_1 L_2 = (-G_1 G_2 H_2)(-G_3 H_3) = +G_1 G_2 G_3 H_2 H_3}$$ Loops $L_3$ and $L_4$ span from $x_2$ to $x_7$, hence they touch all other loops. There are no other non-touching pairs, and no triplets.

4. System Graph Determinant ($\Delta$):

$$\Delta = 1 - (L_1 + L_2 + L_3 + L_4) + (L_1 L_2)$$ $$\Delta = 1 - (-G_1 G_2 H_2 - G_3 H_3 - G_1 G_2 G_3 H_1 - G_1 G_4 G_3 H_1) + G_1 G_2 G_3 H_2 H_3$$ Grouping terms strategically: $$\mathbf{\Delta = (1 + G_1 G_2 H_2)(1 + G_3 H_3) + G_1 (G_2 + G_4) G_3 H_1}$$ Notice how the product $(1 + G_1 G_2 H_2)(1 + G_3 H_3)$ emerges directly from $1 - L_1 - L_2 + L_1 L_2$!

5. Path Cofactors ($\Delta_k$):

  • Path 1 ($P_1 = G_1 G_2 G_3$): Traverses $\{R, x_2, x_3, x_4, x_5, x_6, x_7, C\}$, touching all loops $\implies \mathbf{\Delta_1 = 1}$.
  • Path 2 ($P_2 = G_1 G_4 G_3$): Traverses nodes $x_3, x_4$ (touching $L_1$) and nodes $x_6, x_7$ (touching $L_2$). Thus it touches all loops $\implies \mathbf{\Delta_2 = 1}$.

6. Overall Transfer Function:

$$\frac{C(s)}{R(s)} = \frac{P_1 \Delta_1 + P_2 \Delta_2}{\Delta} = \frac{G_1 G_2 G_3(1) + G_1 G_4 G_3(1)}{(1 + G_1 G_2 H_2)(1 + G_3 H_3) + G_1 (G_2 + G_4) G_3 H_1}$$ $$\mathbf{\frac{C(s)}{R(s)} = \frac{G_1 (G_2 + G_4) G_3}{(1 + G_1 G_2 H_2)(1 + G_3 H_3) + G_1 (G_2 + G_4) G_3 H_1}} \quad \blacksquare$$
Examination Verification: The transfer function obtained by Block Diagram Reduction (Method 1) and by Mason's Gain Formula (Method 2) are completely identical. In JU exams, candidates who show this clean grouping $(1 + G_1 G_2 H_2)(1 + G_3 H_3) + G_1 (G_2 + G_4) G_3 H_1$ consistently secure full 100% marks.

Conversion • Topological Mapping

Block Diagram to Signal Flow Graph Conversion Rules and Application

“Construct the Signal Flow Graph for the multi-loop feedback control system shown in Fig. 4.3. Label all intermediate signals and internal nodes. Using Mason's Gain Formula, determine the overall closed-loop transfer function $\frac{C(s)}{R(s)}$.”
Step 1: Systematic Rules for BD to SFG Transformation

Converting an interconnected block diagram into an SFG follows three fundamental transformation rules:

  1. Node Mapping: Assign a distinct SFG node to:
    • The reference input signal $R(s)$ (pure source node).
    • The output of every summing point (representing the resultant error or combined signal).
    • Every signal pick-off point where branches divert.
    • The final controlled variable $C(s)$ (pure sink node, connected via a branch of gain $1$).
  2. Branch Mapping: Replace every block with a directed branch originating from its input node and terminating at its output node. The branch transmittance equals the block transfer function $G_i(s)$ or $H_i(s)$.
  3. Sign Assignment: If an incoming branch enters a summing junction with a negative sign ($-$), assign a minus sign to the corresponding branch transmittance (e.g., $-1$ or $-H_i(s)$). If it enters with a positive sign ($+$), assign a positive sign ($+1$ or $+H_i(s)$).
Step 2: Applied Transformation Example

Consider the canonical feedback structure with forward cascade $G_1, G_2, G_3$, local feedback $H_1$, and outer feedback $H_2$:

  • Forward Path: $P_1 = G_1 G_2 G_3$ with cofactor $\Delta_1 = 1$.
  • Inner Loop: $L_1 = -G_2 H_1$.
  • Outer Loop: $L_2 = -G_1 G_2 G_3 H_2$.
  • Determinant: $\Delta = 1 - (L_1 + L_2) = 1 + G_2 H_1 + G_1 G_2 G_3 H_2$.
  • Transfer Function: $$\frac{C(s)}{R(s)} = \frac{G_1 G_2 G_3}{1 + G_2 H_1 + G_1 G_2 G_3 H_2} \quad \blacksquare$$

Algebraic Operations • Fast Examination Cheatsheet

Summary of Essential Block Diagram Equivalence Transformations

In semester exams, never write proofs for these rules unless explicitly asked. Use them directly to transform complex diagrams:

Operation Original Configuration Transformed Equivalent Rule
1. Blocks in Cascade (Series) $X \to [G_1] \to [G_2] \to Y$ Multiply gains: $G_{\text{eq}} = G_1 G_2$.
2. Blocks in Parallel $X$ branches to $[G_1]$ and $[G_2]$, summing into $Y$ Add gains algebraically: $G_{\text{eq}} = G_1 \pm G_2$.
3. Eliminating Feedback Loop Forward $G$, feedback $H$ into summer with $\mp$ sign $G_{\text{eq}} = \frac{G}{1 \pm GH}$ ($-$ gives $+$; $+$ gives $-$).
4. Moving Summer Behind Block Summer located before block $G$ Move summer after $G$; insert block $G$ into other incoming branch.
5. Moving Summer Ahead of Block Summer located after block $G$ Move summer before $G$; insert block $\frac{1}{G}$ into other incoming branch.
6. Moving Takeoff Behind Block Pick-off located before block $G$ Move pick-off after $G$; insert block $\frac{1}{G}$ into tapped branch.
7. Moving Takeoff Ahead of Block Pick-off located after block $G$ Move pick-off before $G$; insert block $G$ into tapped branch.
8. Swapping Adjacent Summers Summer 1 followed immediately by Summer 2 Summers can be interchanged directly ($A + B + C = A + C + B$).
