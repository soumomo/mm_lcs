1.0 Introduction & Physical Notion of Stability

Verbatim alignment with Prof. MM's handwritten lecture notes (Pages 4–13)

MM Prof. MM's Opening Lecture Note (Page 4):
"The problem of stability of a system or plant is the prime concern of the system engineers or control system engineers. Initially it was assumed that if a system exhibited sustained oscillation in the output even for a reasonable input and the sustained oscillation was unwanted, the system would be considered as an unstable one. However, this consideration cannot justify the concept of stability of a system properly.

Roughly speaking, stability in a system implies that small changes in the system input, in initial conditions or in system parameters do not result in large changes in system output.

Moreover, stability is a notion that describes whether the output can follow the input command (obviously bounded) or whether the output gradually deviates further and further from the input."

❖ Typical Control Problems (Prof. MM Notes Page 5 & Fig 1.1)

Prof. MM categorizes all control systems into two foundational control problems to illustrate stability:

Problem 1 Fixed Setpoint

The Regulatory Problem

"Set point is fixed and acts as the input to the system. Say temperature control of a room. Set point temperature, say, $25^\circ\text{C}$ at which the temperature of the room is to be maintained."

• Stable System:

The output of the controlled system reaches and stays at $25^\circ\text{C}$ at steady state.

• Unstable System:

Instead of staying at $25^\circ\text{C}$, the room temperature goes on increasing without bound!

Problem 2 Time-Varying Command

The Tracking Problem

"Trajectory tracking of a missile. Here input is not constant like $25^\circ\text{C}$. Input is varying with a predefined pattern, e.g., the desired trajectory of the missile."

• Stable System:

The controlled output tracks and follows the dynamically moving reference trajectory.

• Unstable System:

The output digresses further and further away from the desired input trajectory!

💡 Why Stability is Non-Negotiable (Prof. MM's Human Analogy, Page 6-7)

Prof. MM explains why stability must precede any other performance metric:

"Just think about a situation! Suppose I have asked one of you to lift a 'load', and god forbid, you are not doing well. So, if you try to follow the input command, since you are not doing well and are not stable, you may start trembling (unwanted oscillation kind of response) and finally, before you can execute the task, you may collapse!
So, the entire purpose/task to be executed will be defeated!!
So, we conclude that if a system is unstable we, the control system engineers, cannot make the system functional."
** The Three Sequential Tasks of a Control System Engineer (MM Notes Page 7):
Step 1: Ascertain Stability Test if the system or plant is stable.
Step 2: Stabilize System If unstable, the primary job is to design feedback/control to make it stable.
Step 3: Performance Analysis Once stable, analyze and enhance performance (steady-state error, speed of response).

📝 Prof. MM Assignment #1.1 & #1.2: Dynamic Systems vs Static Systems
Assignment #1.1: What is a Dynamic System?

A dynamic system is one whose output at any instant $t$ depends not only on the current input $u(t)$, but also on the past history of inputs and internal energy states (stored in capacitors, inductors, springs, or masses). Mathematically governed by differential equations: $$\dot{\mathbf{x}}(t) = \mathbf{A}\mathbf{x}(t) + \mathbf{B}u(t), \quad y(t) = \mathbf{C}\mathbf{x}(t) + D u(t)$$

Assignment #1.2: Distinguish Static vs Dynamic

• Static System (Memoryless): Output depends strictly on instantaneous input $y(t) = f(u(t))$ (e.g. pure resistive voltage divider $v_o = \frac{R_2}{R_1+R_2}v_i$). No differential equations, no energy storage, no transient dynamics.
• Dynamic System (With Memory): Possesses energy storage elements, transient response, natural oscillation modes, and differential equations.

Mathematical Definitions & Classifications

Zero-Input (Asymptotic) vs Zero-State (BIBO) Stability, Impulse Integrability, and the Pole-Zero Cancellation Trap

Internal Property Zero-Input Response

1. Asymptotic Stability

A linear time-invariant system is defined as asymptotically stable if, with zero external excitation ($u(t) = 0$), its unforced state response $\mathbf{x}(t)$ returns to the origin as time approaches infinity, regardless of the initial state:

$$\lim_{t \to \infty} \|\mathbf{x}(t)\| = 0 \quad \text{for any finite } \mathbf{x}(0)$$

Physical meaning: All internally stored energy (in inductors, capacitors, springs, masses) naturally dissipates to zero without replenishment.

Input-Output Property Zero-State Response

2. BIBO Stability

A relaxed system (zero initial conditions, $\mathbf{x}(0) = \mathbf{0}$) is BIBO (Bounded-Input Bounded-Output) stable if every bounded input produces a bounded output:

$$|u(t)| \le M_u < \infty \implies |y(t)| \le M_y < \infty \quad \forall t \ge 0$$

Physical meaning: If you supply finite input energy (e.g. 5V step), the output won't blow up to kilovolts or infinity.

★ Theorem: Condition for BIBO Stability of an LTI System

Necessary & Sufficient

An LTI system with impulse response $g(t)$ is BIBO stable if and only if its impulse response is absolutely integrable over $[0, \infty)$:

$$\int_0^\infty |g(t)| \, dt < \infty$$
Proof of Sufficiency & Necessity:

The zero-state output is given by the convolution integral: $$y(t) = \int_0^\infty g(\tau) u(t - \tau) \, d\tau$$

Taking absolute values on both sides and utilizing the triangle inequality for integrals: $$|y(t)| = \left| \int_0^\infty g(\tau) u(t - \tau) \, d\tau \right| \le \int_0^\infty |g(\tau)| \cdot |u(t - \tau)| \, d\tau$$

Since the input is bounded ($|u(t)| \le M_u < \infty$ for all $t$): $$|y(t)| \le M_u \int_0^\infty |g(\tau)| \, d\tau$$

Therefore, if $\int_0^\infty |g(\tau)| \, d\tau = K < \infty$, then $|y(t)| \le M_u K = M_y < \infty$. Hence, output is guaranteed bounded (Sufficiency $\checkmark$).

Necessity: To prove necessity, construct a specific input $u(t - \tau) = \text{sgn}[g(\tau)]$. Then $y(t) = \int_0^\infty |g(\tau)| \, d\tau$. If this integral diverged to $\infty$, this bounded input would produce unbounded output. Hence integrability is strictly necessary. $\blacksquare$

JU Semester Exam Question (2017 Q6b) • Conceptual Pillar

"Does BIBO stability imply asymptotic stability? Explain with an explicit counterexample."

NO. In general, BIBO stability does NOT imply asymptotic stability. BIBO stability only observes the input-to-output transmission path. If an internal subsystem possesses an unstable eigenvalue that is uncontrollable (isolated from the input) or unobservable (isolated from the output), pole-zero cancellation hides the instability from the transfer function $G(s)$, but internal physical variables diverge!

Formal Counterexample (State-Space Representation):

Consider a 2nd-order system described by state equations:

$$\dot{x}_1(t) = x_1(t) + u(t) \quad \text{(Pole at } s = +1 \text{, unstable)}$$ $$\dot{x}_2(t) = -2x_2(t) + u(t) \quad \text{(Pole at } s = -2 \text{, stable)}$$ $$y(t) = x_2(t) \quad \text{(Output connects only to } x_2\text{)}$$

1. Input-Output Transfer Function: Taking Laplace transforms with zero initial conditions: $$Y(s) = X_2(s) = \frac{1}{s + 2} U(s) \implies G(s) = \frac{Y(s)}{U(s)} = \frac{1}{s + 2}$$ The transfer function pole is at $s = -2$ (strictly in LHP). Thus, the system is BIBO STABLE!

2. Zero-Input State Evolution: Now let $u(t) = 0$ with initial state $x_1(0) = c \neq 0$: $$x_1(t) = c e^{+t} \implies \lim_{t \to \infty} x_1(t) = \infty$$ State $x_1(t)$ explodes exponentially! Therefore, the system is ASYMPTOTICALLY UNSTABLE!

When ARE they equivalent? BIBO stability is equivalent to asymptotic stability if and only if the transfer function has no pole-zero cancellations in the right-half plane or on the imaginary axis (i.e., the system is completely controllable and observable, known as a minimal realization).

3. Marginal (Critical) Stability

A system is marginally stable if its zero-input or impulse response neither decays to zero nor grows unbounded, but remains strictly bounded for all $t \ge 0$ (such as constant output or undamped sustained sinusoidal oscillations).

Simple Pole at Origin ($s=0$): Impulse response is a step function $g(t) = K \cdot u(t)$. It remains constant at $K$. Output is bounded, but does not decay to zero.
Pair of Simple Poles on $j\omega$-axis ($s = \pm j\omega_0$): Impulse response is undamped sinusoid $g(t) = A \sin(\omega_0 t + \phi)$. Oscillates indefinitely with constant peak amplitude $A$.

1.3 Locations of the Roots of Characteristic Equation on $s$-Plane & Stability

Verbatim alignment with Prof. MM's handwritten lecture notes (Pages 16–27)

Why Unit Impulse is Chosen as the Standard Disturbance

"For a linear system the ultimate response to a bounded disturbing force is independent of the nature of the disturbing force (there is one exception which we shall discuss later on).
Therefore, it is convenient to use unit-impulse as the disturbing force for examining the stability of a system." (MM Notes Page 16)

$$\frac{C_d(s)}{R(s)} = T(s) \implies C_d(s) = T(s) \cdot R(s)$$ $$\text{For unit impulse, } R(s) = 1 \implies c_d(t) = \mathcal{L}^{-1}\{T(s)\}$$

Writing the closed-loop transfer function: $$T(s) = \frac{P(s)}{q(s)} = \frac{b_0 s^m + b_1 s^{m-1} + \dots + b_m}{a_0 s^n + a_1 s^{n-1} + \dots + a_n}$$ The $n$ roots of the characteristic equation $q(s) = 0$ are the closed-loop poles of the system.

The 8 Pole Types & Their Natural Response Modes (MM Notes Page 19)

Verbatim MM Table

MM 1.3.1 Instability Due to Resonance & Solved Lecture Exercises (Pages 22–23)

"Previously, we said that the condition of stability of an LTI system is independent of the nature of the inputs. However, there is ONE EXCEPTION! When a simple system pole (without multiplicity) appears on the imaginary axis, and an input is applied whose Laplace transform has a matching pole on the imaginary axis, the output becomes unbounded!" (MM Notes Page 22-23)

MM Assignment Exercise #1 Step Input Resonance

Given: $T(s) = \frac{4}{s(s + 4)}$ subjected to unit step input $r(t) = u(t)$.

The system has a simple pole at origin $s = 0$. The input is $R(s) = \frac{1}{s}$ (matching pole at origin $s = 0$!).

$$C(s) = T(s)R(s) = \frac{4}{s^2(s + 4)}$$ $$\frac{4}{s^2(s + 4)} = \frac{1}{s^2} - \frac{1/4}{s} + \frac{1/4}{s + 4}$$

Taking inverse Laplace transform:

$$c(t) = t - \frac{1}{4} + \frac{1}{4}e^{-4t}$$

💥 Result: The secular term $t$ grows linearly without bound as $t \to \infty$! Output is UNBOUNDED!

MM Assignment Exercise #2 Sinusoidal Resonance

Given: $T(s) = \frac{1}{(s + 2)(s^2 + 1)}$ subjected to $r(t) = \sin t$.

System has simple poles on $j\omega$-axis at $s = \pm j1$. The input $R(s) = \frac{1}{s^2 + 1}$ has matching poles at $s = \pm j1$!

$$C(s) = \frac{1}{(s + 2)(s^2 + 1)^2}$$

The denominator now possesses repeated poles on the imaginary axis with multiplicity $K = 2$.

$$c(t) = \dots + t [A \cos t + B \sin t]$$

💥 Result: The $t \cos t$ and $t \sin t$ envelope grows linearly without bound as $t \to \infty$! Output is UNBOUNDED!

1.4 Pole Locations & Stability Classification Flowchart (MM Notes Page 25)

Complete Taxonomy
Branch 1: All in LHP

All closed-loop poles lie in the open Left-Half Plane (LHP).

→ The system is ASYMPTOTICALLY STABLE (and BIBO Stable).

Branch 2: Some Poles on $j\omega$-Axis

Some poles lie on imaginary axis, and all remaining poles lie in LHP:

  • Case 2a: Any $j\omega$ pole is repeated $\implies$ UNSTABLE.
  • Case 2b: A simple $j\omega$ pole matches a pole of input $R(s) \implies$ UNSTABLE (Resonance).
  • Case 2c: All $j\omega$ poles are simple and no matching input pole $\implies$ NON-ASYMPTOTICALLY (MARGINALLY) STABLE.
Branch 3: Even a Single Pole in RHP

Even one single closed-loop pole lies in the Right-Half Plane (RHP).

→ The system is ALWAYS UNSTABLE! (Output explodes exponentially).

Parameter Sensitivity Classification (Nagrath & Gopal / MM Notes Page 27):

• Absolutely Stable with respect to a parameter: The system remains stable for all values of this parameter ($0 \le K < \infty$).

• Conditionally Stable with respect to a parameter: The system is stable only for certain bounded ranges of values of this parameter ($K_{\min} < K < K_{\max}$); outside this range, it turns unstable.

Necessary Conditions for Stability & Factored Form Proof

The #1 High-Yield Exam Question: Derivation from Factored Form, Sufficiency for $n \le 2$, and the 3rd-Order Counterexample

🎯
Guaranteed Class Test & Semester Exam Question (5–6 Marks): Appeared in Class Test 2025-26 (Q1), Class Test 2024-25 (Q1), and recurring semester papers. Master every step of this mathematical derivation.

Let the characteristic equation of an $n^{\text{th}}$-order continuous-time LTI system be:

$$q(s) = a_0 s^n + a_1 s^{n-1} + a_2 s^{n-2} + \dots + a_{n-1} s + a_n = 0 \quad (a_0 > 0)$$
Condition 1

Same Algebraic Sign

All coefficients $a_0, a_1, \dots, a_n$ must have the same algebraic sign. By standard convention ($a_0 > 0$), this requires: $$a_i > 0 \quad \forall i \in \{0, 1, \dots, n\}$$

Condition 2

No Missing Coefficients

None of the coefficients may be zero. That is, no intermediate powers of $s$ can be missing between $s^n$ and the constant term $s^0$: $$a_i \neq 0 \quad \forall i \in \{0, 1, \dots, n\}$$

📜 Mathematical Proof from Factored Polynomial Form

Step 1: Express $q(s)$ in terms of its roots

Any $n^{\text{th}}$-degree polynomial can be factored into $m$ first-order factors corresponding to real roots, and $p$ quadratic factors corresponding to complex conjugate root pairs (where $m + 2p = n$):

$$q(s) = a_0 \prod_{k=1}^m (s - s_k) \prod_{l=1}^p \left[(s - s_l)(s - s_l^*)\right] = 0$$
Step 2: Apply the requirement for asymptotic stability

For the system to be asymptotically stable, all roots must strictly lie in the open Left Half of the $s$-plane ($\text{Re}(s_i) < 0$):

  • For real roots: $s_k = -\sigma_k$ with $\sigma_k > 0$.
  • For complex conjugate roots: $s_l, s_l^* = -\sigma_l \pm j\omega_l$ with $\sigma_l > 0$.
Step 3: Substitute stable pole values into the factored polynomial
$$q(s) = a_0 \prod_{k=1}^m (s + \sigma_k) \prod_{l=1}^p \left[(s + \sigma_l)^2 + \omega_l^2\right] = 0$$
Step 4: Expand the elementary quadratic factors

Expanding the complex conjugate factor: $$(s + \sigma_l)^2 + \omega_l^2 = s^2 + 2\sigma_l s + (\sigma_l^2 + \omega_l^2)$$

Notice the signs of the coefficients in each individual factor:

  • In $(s + \sigma_k)$: The coefficients are $1 > 0$ and $\sigma_k > 0$. All strictly positive!
  • In $(s^2 + 2\sigma_l s + \sigma_l^2 + \omega_l^2)$:
    • Coefficient of $s^2$: $1 > 0$.
    • Coefficient of $s$: $2\sigma_l > 0$ (since $\sigma_l > 0$).
    • Constant term: $\sigma_l^2 + \omega_l^2 > 0$ (sum of squares of real numbers).
    All strictly positive!
Step 5: Polynomial multiplication principle

The characteristic polynomial $q(s)$ is formed by multiplying together factors whose coefficients are exclusively strictly positive. When multiplying polynomials with all positive coefficients, every term in the resulting product is a sum of positive products. No term can ever become negative, and no two terms can cancel each other out to produce zero!

Therefore, all coefficients $a_0, a_1, \dots, a_n$ must be strictly positive ($a_i > 0$), and no powers of $s$ can be missing. $\blacksquare$

⚖️ Proof of Sufficiency for 1st and 2nd Order Systems

While the conditions are merely necessary for general $n$, for $n=1$ and $n=2$, they are both necessary and sufficient!

Case A: First-Order ($n = 1$)

$$a_0 s + a_1 = 0 \implies s = -\frac{a_1}{a_0}$$

If $a_0 > 0$ and $a_1 > 0$, the single root is strictly negative real: $$s = -\frac{a_1}{a_0} < 0$$ The pole lies in the open LHP. Hence, the condition is sufficient!

Case B: Second-Order ($n = 2$)

$$a_0 s^2 + a_1 s + a_2 = 0 \implies s_{1,2} = \frac{-a_1 \pm \sqrt{a_1^2 - 4a_0 a_2}}{2a_0}$$

Assume $a_0, a_1, a_2 > 0$:

  • If roots are complex ($a_1^2 < 4a_0 a_2$): Real part is $\text{Re}(s) = -\frac{a_1}{2a_0} < 0$. (LHP $\checkmark$)
  • If roots are real ($a_1^2 \ge 4a_0 a_2$): Since $a_0 a_2 > 0$, $\sqrt{a_1^2 - 4a_0 a_2} < \sqrt{a_1^2} = a_1$. Thus $-a_1 \pm \sqrt{\dots} < 0$. Both roots are strictly negative! (LHP $\checkmark$)

Hence, for $n=2$, the condition is sufficient!

⚠️ Why It Fails for $n \ge 3$: The Counterexample

For polynomials of 3rd degree and above, satisfying all positive coefficients does NOT guarantee stability.

The Classic Counterexample (From MM Notes & CT 2025):

$$q(s) = s^3 + s^2 + 2s + 8 = 0$$
  • All coefficients are strictly positive: $a_0 = 1, a_1 = 1, a_2 = 2, a_3 = 8 > 0$.
  • No power of $s$ is missing ($s^3, s^2, s^1, s^0$ are all present).
  • Necessary condition is 100% satisfied!

Now factor the polynomial exactly:

$$q(s) = (s + 2)(s^2 - s + 4) = 0$$

Evaluating the roots:

$$s_1 = -2 \quad \text{(Stable real pole in LHP)}$$ $$s_{2,3} = \frac{-(-1) \pm \sqrt{(-1)^2 - 4(1)(4)}}{2} = \frac{1 \pm j\sqrt{15}}{2} = \mathbf{+0.5 \pm j1.9365}$$
💥 Fatal Result: Real part is $\sigma = +0.5 > 0$! Two complex conjugate poles lie in the Right-Half $s$-Plane. The system is UNSTABLE!

1.6 Hurwitz Stability Criterion

Verbatim alignment with Prof. MM's lecture notes (Pages 30–31) & JU Exam 2017 Q6a

"We know that the characteristic equation of an n-th order system is: $$q(s) = a_0 s^n + a_1 s^{n-1} + \dots + a_{n-1} s + a_n = 0; \quad a_0 > 0$$ For the stability of the system, it is necessary and sufficient that the 'n' determinants formed from the coefficients $a_0, a_1, \dots, a_n$ of the characteristic equation be positive, where these determinants are taken as the principal minors of the Hurwitz determinant." (MM Notes Pages 30–31)

Construction of the Hurwitz Matrix $H$

$$H = \begin{bmatrix} a_1 & a_0 & 0 & 0 & \dots & 0 \\ a_3 & a_2 & a_1 & a_0 & \dots & 0 \\ a_5 & a_4 & a_3 & a_2 & \dots & 0 \\ \vdots & \vdots & \vdots & \vdots & \ddots & \vdots \\ 0 & 0 & 0 & 0 & \dots & a_n \end{bmatrix}_{n \times n}$$

The coefficients with indices larger than $n$ or with negative indices are replaced by zeros.

$$\Delta_1 = a_1 > 0$$
$$\Delta_2 = \begin{vmatrix} a_1 & a_0 \\ a_3 & a_2 \end{vmatrix} = a_1 a_2 - a_0 a_3 > 0$$
$$\Delta_3 = a_3 \Delta_2 - a_1(a_1 a_4 - a_0 a_5) > 0$$

Example 6.1: Fourth-Order System (Nagrath & Gopal / MM Notes Page 31)

Verbatim MM Slide

Consider a fourth-order system with the characteristic equation: $$q(s) = s^4 + 8s^3 + 18s^2 + 16s + 5 = 0$$ Here: $a_0 = 1, \quad a_1 = 8, \quad a_2 = 18, \quad a_3 = 16, \quad a_4 = 5$.

The Hurwitz arrangement is:

$$H = \begin{bmatrix} 8 & 1 & 0 & 0 \\ 16 & 18 & 8 & 1 \\ 0 & 5 & 16 & 18 \\ 0 & 0 & 0 & 5 \end{bmatrix}$$
$$\Delta_1 = 8 > 0$$
$$\Delta_2 = \begin{vmatrix} 8 & 1 \\ 16 & 18 \end{vmatrix} = 8(18) - 1(16) = 144 - 16 = \mathbf{128 > 0}$$
$$\Delta_3 = \begin{vmatrix} 8 & 1 & 0 \\ 16 & 18 & 8 \\ 0 & 5 & 16 \end{vmatrix} = 8(18 \times 16 - 40) - 1(256 - 0) = \mathbf{1,728 > 0}$$
$$\Delta_4 = a_4 \Delta_3 = 5 \times 1,728 = \mathbf{8,640 > 0}$$

Conclusion: Since all principal minors $\Delta_1, \Delta_2, \Delta_3, \Delta_4$ are strictly positive, the system is ASYMPTOTICALLY STABLE! $\blacksquare$

🎓 JU Semester Exam Question (2017 Q6a): Relation Between Routh Array & Hurwitz Determinants

"Derive the mathematical relationship between the elements of the first column of the Routh array and the Hurwitz determinants."

Consider the general characteristic polynomial $a_0 s^n + a_1 s^{n-1} + a_2 s^{n-2} + \dots = 0$. In the Routh array:

Row $s^n$: $r_{1,1} = a_0$
Row $s^{n-1}$: $r_{2,1} = a_1 = \Delta_1$
Row $s^{n-2}$: $r_{3,1} = b_1 = \frac{a_1 a_2 - a_0 a_3}{a_1} = \frac{\Delta_2}{\Delta_1}$
Row $s^{n-3}$: $r_{4,1} = c_1 = \frac{b_1 a_3 - a_1 b_2}{b_1} = \frac{\Delta_3}{\Delta_2}$
General Induction: $r_{k, 1} = \frac{\Delta_{k-1}}{\Delta_{k-2}}$ for row $k \ge 2$

Why Routh's array is computationally superior: Evaluating an $n \times n$ determinant directly requires $\mathcal{O}(n!)$ operations. Routh's array utilizes Gaussian-type triangularization, reducing the entire test to $\mathcal{O}(n^2)$ arithmetic operations! $\blacksquare$

The Routh Stability Array Algorithm

Array Construction, Cross-Multiplication Determinants, and Sign Change Theorem

Edward John Routh (1877) simplified the computation of stability by introducing a tabular array that calculates the stability criteria systematically without computing full determinants.

Standard Structure of the Routh Array

For $q(s) = a_0 s^n + a_1 s^{n-1} + a_2 s^{n-2} + a_3 s^{n-3} + \dots + a_n = 0$:

Power of $s$ Column 1 Column 2 Column 3 Column 4
$s^n$ $a_0$ $a_2$ $a_4$ $a_6 \dots$
$s^{n-1}$ $a_1$ $a_3$ $a_5$ $a_7 \dots$
$s^{n-2}$ $b_1$ $b_2$ $b_3$ $\dots$
$s^{n-3}$ $c_1$ $c_2$ $\dots$ $\dots$
$\vdots$ $\vdots$ $\vdots$ $\vdots$ $\vdots$
$s^0$ $a_n$ - - -
$$b_1 = \frac{a_1 a_2 - a_0 a_3}{a_1} = -\frac{1}{a_1} \begin{vmatrix} a_0 & a_2 \\ a_1 & a_3 \end{vmatrix}$$ $$b_2 = \frac{a_1 a_4 - a_0 a_5}{a_1} = -\frac{1}{a_1} \begin{vmatrix} a_0 & a_4 \\ a_1 & a_5 \end{vmatrix}$$
$$c_1 = \frac{b_1 a_3 - a_1 b_2}{b_1} = -\frac{1}{b_1} \begin{vmatrix} a_1 & a_3 \\ b_1 & b_2 \end{vmatrix}$$ $$c_2 = \frac{b_1 a_5 - a_1 b_3}{b_1} = -\frac{1}{b_1} \begin{vmatrix} a_1 & a_5 \\ b_1 & b_3 \end{vmatrix}$$

📜 Routh's Stability Criterion Theorem

The number of roots of $q(s) = 0$ with positive real parts (lying in the open Right-Half $s$-Plane) is exactly equal to the number of sign changes in the first column of the Routh array.

• Asymptotically stable $\iff$ all elements in the first column have the same sign (no sign changes).

💡 Row Simplification Rule

Any row of the Routh array may be multiplied or divided by any strictly positive constant without altering the signs of the elements in that row or any subsequent rows!

• Use this to eliminate messy fractions during exams and avoid arithmetic errors.

1.8 Some Key Points & 1.9 More on Routh's Stability Criterion

Verbatim text and advanced problem from Prof. Madhubanti Maitra's concluding lecture notes (Pages 38–41)

1.8 Prof. MM's Lecture Reflections: "Some Key Points" (Page 38–39)
Prof. MM's Exact Definition: What is Meant by "Absolute Stability"?
"The answer to this question is that the concept of Absolute Stability is basically a YES/NO criterion. If the system is stable and if we ask whether the system is absolutely stable or not; the answer would be YES! And if the system is not stable or unstable, if we ask the question whether the system is stable or not, the answer would be NO!" (MM Notes Page 38)
1. Standard Case Stability

While applying Routh-Hurwitz criteria, if we do not encounter any special cases, the conclusion is clear-cut: YES (stable, no sign change in Col 1 or all principal minors positive) or NO (unstable).

2. Parameter Sensitivity in Marginally Stable Systems

Limitedly or marginally stable systems with simple poles on the imaginary axis "may become stable or unstable due to slight variations in system parameters (reflected in changes in characteristic equation coefficients!)".

Why Routh over Hurwitz: For higher order systems (e.g. 6th order), evaluating a $6 \times 6$ determinant directly is tedious and error-prone. Routh's array solves stability in simple arithmetic steps.

1.9 1.9 More on Routh's Stability Criterion & The $\epsilon$-Method Failure Trap (Pages 39–41)
Observation 1: Early Termination Rule (Save Time in Exams!)

"During the formation of a Routh array, if at any stage a row (not containing all zero terms) having one or more zero elements and/or one or more negative elements appears, the completion of Routh array will ALWAYS result in sign changes in the first column (i.e. roots in RHS-plane). Therefore, for stability determination, we need not proceed with array formation anymore, unless we are specifically asked for the exact count of RHS-plane roots!" (MM Notes Page 39)

Observation 2: Why the $\epsilon$-Method FAILS in the Presence of Imaginary Axis Roots!

The Rationale: The $\epsilon$-method mathematically represents a small perturbation of the polynomial coefficients. If all roots have non-zero real parts, small perturbations will not alter the count of RHP roots.

The Fatal Breakdown: "If the characteristic polynomial has roots on the imaginary axis, replacing the first-column zero by $\epsilon$ would cause the imaginary axis roots to shift into either the Left or Right half of the $s$-plane, with the result that the number of roots in the RHS-plane CANNOT be correctly determined!" (MM Notes Page 40)

The Mandatory Remedy: "Therefore, to apply the $\epsilon$-limiting method for a polynomial with imaginary-axis roots, one must FIRST EXTRACT these roots (using the auxiliary equation) before the test is applied on the remainder polynomial!"

Class Test 2025-26 • Q1 [5 Marks • 15-10-2025]
100% Guaranteed Topic

"State the necessary conditions for stability of a linear continuous-time system. Derive these conditions from the factored form of the characteristic polynomial. Prove that these conditions are sufficient for 1st and 2nd order systems, but not sufficient for 3rd order systems with an example."

Part A: Statement of Necessary Conditions

For characteristic equation $q(s) = a_0 s^n + a_1 s^{n-1} + \dots + a_n = 0$ ($a_0 > 0$), to have all roots in the open Left-Half Plane:

  1. All coefficients $a_i$ must have the same algebraic sign ($a_i > 0$ for all $i = 0, 1, \dots, n$).
  2. None of the coefficients may be zero ($a_i \neq 0$ for all $i$). No intermediate powers of $s$ can be missing.
Part B: Factored Form Derivation

Factor $q(s)$ into its $m$ real roots $-\sigma_k$ and $p$ complex conjugate pairs $-\sigma_l \pm j\omega_l$:

$$q(s) = a_0 \prod_{k=1}^m (s + \sigma_k) \prod_{l=1}^p \left[(s + \sigma_l)^2 + \omega_l^2\right] = 0$$

For asymptotic stability, all real parts must be strictly negative $\implies \sigma_k > 0$ and $\sigma_l > 0$. Expanding the quadratic factor:

$$(s + \sigma_l)^2 + \omega_l^2 = s^2 + 2\sigma_l s + (\sigma_l^2 + \omega_l^2)$$

Since $\sigma_l > 0$, coefficient of $s$ is $2\sigma_l > 0$. Since $\sigma_l^2 + \omega_l^2 > 0$, the constant term is strictly positive. Every elementary factor contains only strictly positive coefficients. Since the product of polynomials with strictly positive coefficients can only yield strictly positive coefficients with no negative terms or zero-cancellations, all coefficients $a_0, a_1, \dots, a_n$ must be strictly positive and non-zero. $\blacksquare$

Part C: Sufficiency for $n=1$ and $n=2$
  • 1st Order ($a_0 s + a_1 = 0$): Root $s = -a_1/a_0$. Since $a_0, a_1 > 0$, root is strictly negative. (Sufficient $\checkmark$)
  • 2nd Order ($a_0 s^2 + a_1 s + a_2 = 0$): Roots $s = \frac{-a_1 \pm \sqrt{a_1^2 - 4a_0 a_2}}{2a_0}$. If complex, $\text{Re}(s) = -a_1/(2a_0) < 0$. If real, $\sqrt{a_1^2 - 4a_0 a_2} < a_1 \implies -a_1 \pm \sqrt{\dots} < 0$. Both roots strictly negative. (Sufficient $\checkmark$)
Part D: Why NOT Sufficient for $n=3$ (Counterexample)

Consider $q(s) = s^3 + s^2 + 2s + 8 = 0$. All coefficients are positive ($1, 1, 2, 8 > 0$) and none are missing. Factoring gives:

$$(s + 2)(s^2 - s + 4) = 0 \implies s_1 = -2, \quad s_{2,3} = \mathbf{+0.5 \pm j1.936}$$

Real part is $+0.5 > 0$ (poles in RHP $\implies$ UNSTABLE). Hence, positive coefficients are not sufficient for $n \ge 3$. $\blacksquare$

"A unity negative feedback control system has open-loop transfer function: $$G(s) = \frac{K(s + 1)}{s^3 + b s^2 + 3s + 1}, \quad H(s) = 1$$ It is known that the closed-loop system exhibits sustained oscillations with frequency $\omega = 2\text{ rad/sec}$.

(b) Check whether any other roots lie in the Right-Half $s$-Plane for these parameter values."

$$1 + G(s)H(s) = 0 \implies 1 + \frac{K(s + 1)}{s^3 + b s^2 + 3s + 1} = 0$$ $$s^3 + b s^2 + 3s + 1 + K s + K = 0$$ $$\mathbf{q(s) = s^3 + b s^2 + (3 + K)s + (1 + K) = 0}$$

Step 3: Apply Sustained Oscillation Condition ($\omega = 2\text{ rad/s}$)

For sustained undamped oscillations, the system must be marginally stable with a pair of imaginary roots at $s = \pm j2$. This requires row $s^1$ to be an all-zero row:

$$b(3 + K) - (1 + K) = 0 \implies 3b + bK - 1 - K = 0 \quad \text{--- (Eq. 1)}$$

From row $s^2$, the Auxiliary Equation $A(s) = 0$ contains the symmetric oscillatory roots:

Step 4: Solve for Parameters $b$ and $K$

Substitute Eq. 2 ($K = 4b - 1$) into Eq. 1 ($b(3+K) - (1+K) = 0$):

$$b\left(3 + [4b - 1]\right) - 4b = 0$$ $$b(4b + 2) - 4b = 0$$ $$4b^2 + 2b - 4b = 0 \implies 4b^2 - 2b = 0 \implies 2b(2b - 1) = 0$$

Since $b > 0$ for physical stability ($b=0$ violates necessary condition):

$$2b - 1 = 0 \implies \mathbf{b = 0.5 = \frac{1}{2}}$$

Now substitute $b = 0.5$ back into Eq. 2 to find $K$:

$$K = 4(0.5) - 1 = 2 - 1 \implies \mathbf{K = 1}$$

60-Second Exam Cheat Sheet & Key Rules

Essential rules, quick formulas, and memory shortcuts for exam morning

Rule 1 • Necessary Conditions

All $a_i > 0$ and no missing powers of $s$.

• $n=1, 2$: Necessary AND sufficient.
• $n \ge 3$: Necessary, but NOT sufficient! (Remember $s^3 + s^2 + 2s + 8 = 0$).

Rule 2 • 3rd Order Quick Rule

For $a_0 s^3 + a_1 s^2 + a_2 s + a_3 = 0$:

$\mathbf{a_1 a_2 > a_0 a_3}$ for stability.
$a_1 a_2 = a_0 a_3 \implies$ Sustained oscillation at $\omega = \sqrt{a_3/a_1}$.

Rule 3 • Routh's Theorem

Sign Changes in Col 1 = Roots in RHP.

Any row may be multiplied or divided by a positive constant $k > 0$ to avoid awkward fractions!

Rule 4 • Special Case 1 ($\epsilon$)

First element 0, but other entries non-zero:

Replace 0 with small $\epsilon > 0$ and inspect limit $\epsilon \to 0^+$, OR substitute $s = 1/z$ and reverse coefficient order.

Rule 5 • Special Case 2 (Row of 0s)

Entire row vanishes $\implies$ symmetric roots!

1. Form even polynomial $A(s)$ from previous row.
2. Replace zero row with $\frac{dA(s)}{ds}$.
3. Set $s^2 = -\omega_{osc}^2$ in $A(s)=0$ for oscillation frequency.

Rule 6 • Relative Stability

Substitute $\mathbf{s = z - \sigma_0}$.

Guarantees all roots have damping faster than $e^{-\sigma_0 t}$, giving settling time $t_s \le \frac{4}{\sigma_0}$.
